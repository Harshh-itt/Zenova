# 🌿 Zenova — Productivity & Focus Tracker

Zenova is a web-based productivity and focus management application designed to help users organize tasks, maintain focus, and track their productivity.

The application combines a **Pomodoro Timer, Task Management, Focus Analytics, and Focus Music** into a single interface.

---

## ✨ Features

### ⏱️ Pomodoro Focus Timer
- 25-minute focus sessions
- Break sessions
- Start, pause, and reset controls
- Helps users follow the Pomodoro productivity technique

### ✅ Task Management
- Add tasks
- Manage daily tasks
- Mark tasks as completed
- Store task data using browser Local Storage

### 📊 Focus Analytics
- Track productivity-related statistics
- Display completed tasks and focus information
- Provides a visual overview of user productivity

### 🎵 Focus Music
- Integrated focus music player
- Play and pause controls
- Designed to provide background music during focus sessions

### 💾 Local Storage
- Tasks and relevant application data are stored locally in the browser
- Data remains available after refreshing the page

### 📱 Responsive Interface
- Responsive layout
- Sidebar-based navigation
- Designed for desktop and smaller screen sizes
